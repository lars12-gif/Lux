# LUX BOT — WhatsApp / Node.js

بوت إدارة أولي لنقابة LUX باستخدام Node.js وBaileys. يدعم ربط رقم واتساب، إنشاء قناة الاستمارات عبر `newsletterCreate` عند توفرها في إصدار المكتبة، نشر الاستمارات، وإنشاء مجموعات الفروع وحفظ معرّفاتها، بالإضافة إلى عرض نظام الرتب والنقاط.

## مهم قبل التشغيل

- يتطلب Node.js 20 أو أحدث.
- المكتبة المستخدمة `@itsliaaa/baileys` فرع غير رسمي من Baileys. الاتصال يتم عبر واجهة WhatsApp Web غير الرسمية، وقد تتغير واجهاتها أو تتوقف بعض الوظائف.
- لا يوجد ضمان أن واتساب يسمح بإنشاء القناة/المجموعة من كل حساب أو منطقة أو إصدار.
- لا تستخدم البوت للإرسال الجماعي المزعج. قد يؤدي الاستخدام المخالف إلى تقييد الرقم.
- لا ترفع مجلد `auth/` أو ملف `.env` إلى GitHub. يحتوي `auth/` على جلسة دخول رقمك.

## النشر على استضافة Node.js

1. ارفع محتويات المجلد إلى مستودع GitHub خاص.
2. أنشئ خدمة Node.js على الاستضافة واربطها بالمستودع.
3. اختر Node.js 20+، وأمر التثبيت `npm install` وأمر التشغيل `npm start`.
4. انسخ `.env.example` إلى متغيرات البيئة في لوحة الاستضافة، وتم إعداد `OWNER_NUMBER` و`PAIRING_NUMBER` مبدئياً برقم التأسيس الذي زوّدتنا به؛ راجعهما قبل التشغيل.
5. شغّل الخدمة وافتح Logs. استخدم رمز الاقتران الظاهر في Logs: واتساب > الأجهزة المرتبطة > ربط جهاز > الربط برقم الهاتف. إذا تعذر إصدار الرمز، سيظهر QR كخيار بديل.
6. تأكد من أن الاستضافة تحفظ مجلدَي `auth/` و`data/` على قرص دائم (Persistent Disk). إذا كان نظام الملفات مؤقتاً، قد يطلب QR من جديد بعد إعادة النشر.
7. بعد الاتصال، سيحاول البوت إنشاء قناة الاستمارات تلقائياً إذا كان `AUTO_CREATE_FORMS_CHANNEL=true`.

## الأوامر

اكتب `!lux help` في محادثة البوت أو مجموعة يوجد فيها:

- `!lux status`
- `!lux create-channel`
- `!lux create-groups`
- `!lux forms`
- `!lux form s` — يعرض نموذج S فقط
- `!lux post s` — ينشر نموذج S في قناة الاستمارات
- `!lux post m` / `!lux post l`
- `!lux post welcome`
- `!lux post work`
- `!lux post winner`
- `!lux post promotion`
- `!lux post announcement`
- `!lux post points`
- `!lux post member`
- `!lux posttext نص الاستمارة`
- `!lux ranks`
- `!lux rankrules`
- `!lux pointcalc 5000 20`

الأوامر الإدارية محمية برقم المؤسس والأرقام في `ADMIN_NUMBERS`.

## إنشاء القروبات

`!lux create-groups` ينشئ مجموعات مستقلة:
- LUX MAIN GUILD
- LUX RECEPTION
- LUX WORK
- LUX ADMIN
- LUX ANNOUNCEMENTS

يحتاج إلى رقم إضافي واحد على الأقل في `ADMIN_NUMBERS` ليُضاف كعضو أول؛ رقم البوت نفسه هو منشئ المجموعة. قد ترفض واتساب الإضافة حسب إعدادات الخصوصية؛ راجع المجموعة يدوياً بعد الإنشاء. هذا الإصدار لا ينشئ WhatsApp Community ولا يربط المجموعات داخل مجتمع تلقائياً.

## قناة الاستمارات

اسم القناة الافتراضي `LUX | FORMS`. عند نجاح الإنشاء يحفظ البوت معرّف القناة في `data/lux-data.json` ثم يرسل النماذج إليها.
إذا فشل الإنشاء:
1. أنشئ القناة يدوياً من واتساب > التحديثات > القنوات > + > إنشاء قناة.
2. إذا كان إرسال الأوامر داخل القناة مدعوماً في نسخة واتساب، أرسل `!lux set-channel` منها.
3. وإلا انسخ معرّف القناة إلى `channelJid` داخل `data/lux-data.json` ثم أعد تشغيل البوت.

## نظام LUX المضمّن

الرتب:
- مشرف تدريبي: 600 نقطة تفاعل بيوم.
- ملازم: 5,000 نقطة + 20 طرف.
- نقيب: 10,000 نقطة + 50 طرف.
- كوماندر: 12,500 نقطة + 75 طرف.
- عقيد: 15,000 نقطة + 100 طرف.
- سينزو: 20,000 نقطة + 150 طرف.
- مورتي: 25,000 نقطة + 200 طرف.
- نائب ليشر: يحددها المؤسس.
- ليشر: المؤسس.

النقاط:
- فعالية S = 20، M = 50، L = 100.
- دخول شخص من طرفك = 50.
- استقبال عضو (ترحيب + ورْك) = 25.
- التفاعل حسب شرائح الرسائل الواردة في ملف LUX.
- مكافآت أسبوعية: أفضل متفاعل/ناشر/مشرف = 500 نقطة، مع شرط 25 شخصاً على الأقل لأفضل ناشر.
- الخصومات: إنذار -25، طرد تأديبي/إنذار إداري -100، طرد مؤقت/خروج بدون إذن -200.

**مهم:** البوت في هذا الإصدار يعرض القواعد ويحسب أهلية الرتبة من الأرقام التي تدخلها الإدارة؛ لا يراقب عدد الرسائل أو يحتسب الأطراف والنقاط تلقائياً بعد. لا تعتمد عليه كسجل نهائي للنقاط قبل إضافة آلية التتبع ومراجعة الإدارة.

## ملفات مهمة

- `src/index.js`: اتصال واتساب والأوامر.
- `src/forms.js`: قوالب الاستمارات والرتب والنقاط.
- `src/groups.js`: إنشاء المجموعات.
- `src/storage.js`: تخزين JSON.
- `data/lux-data.json`: ينشأ تلقائياً بعد أول تشغيل.
